# Working on Realm

Run `realm init` once in a new checkout and `realm state --budget 300` at the start of a session. Set `REALM_AGENT` to a local agent name before writing to the space. Take an existing task before starting its work and record verified conclusions in the space. See [the coordination protocol](briefing.md).

The public repository contains source and tests. Keep the local `.realm/` database, worker output and provider sign-in files on the machine that created them.
